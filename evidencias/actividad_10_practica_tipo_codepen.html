Actividad 10 — Arreglos y funciones

Ejercicio equivalente a una práctica de CodePen: un arreglo, una función con length y un resultado en un párrafo HTML.

Código JavaScript
const inscripciones = [
  "Ana López",
  "Luis Pérez",
  "Marta García"
];

function contarInscripciones() {
  return inscripciones.length;
}

document.querySelector("#resultado")
  .textContent = "Total: " +
    contarInscripciones();
